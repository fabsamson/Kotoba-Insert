# Dictionary attribution

Kotoba Insert uses optional locally installed dictionary snapshots generated by [kotoba-insert-data](https://github.com/fabsamson/kotoba-insert-data).

Those snapshots are derived from JMdict data provided by the Electronic Dictionary Research and Development Group (EDRDG), and are distributed under CC BY-SA 4.0. The plugin presents this source information in Settings and retains the installed snapshot metadata locally.

- JMdict project: https://www.edrdg.org/wiki/index.php/JMdict-EDICT_Dictionary_Project
- EDRDG licence: https://www.edrdg.org/edrdg/licence.html
- Data project: https://github.com/fabsamson/kotoba-insert-data
